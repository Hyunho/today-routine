# 2026-10-07 기기 간 동기화 복구

## 실제 기기에서 확인한 상태

- Mac 빌드 32, iPhone 빌드 20은 동일한 동기화 공간을 사용하고 있었다.
- Mac 폴더 북마크 복원은 Cocoa 오류 259로 실패했다. Mac DB에는 174개 이벤트 중 54개가 미전송 상태였다.
- iPhone DB에는 공유 폴더와 같은 137개 이벤트가 있었으며, 그중 17개가 Mac에 아직 적용되지 않았다.
- 복구 전 두 기기의 SQLite 백업을 `/private/tmp/routine-{mac,phone}-before-recovery.sqlite`에 보관했다.

## 원인과 조치

1. 로컬 비샌드박스 Mac 배포본의 일반 북마크를 `.withSecurityScope`로만 복원해 오류가 발생했다. 같은 북마크의 일반 복원은 성공했다.
   - 해당 형식 오류일 때만 일반 북마크 복원을 시도한다. 손상된 북마크는 계속 오류로 처리하며, 경로 문자열로 우회하지 않는다.
   - 빌드 33을 개발자 서명으로 설치하고 재실행하여, 폴더 재선택 없이 연결이 복원되는 것을 확인했다.
2. 폴더 재연결 후 과거 CSV의 iCloud 다운로드 대기가 전체 배치를 막았다. 로그에서 `manifest.json`, `baseline.json`, `루틴.csv`를 한 개씩 요청하고 재시도하는 동작을 확인했다.
   - 기존 폴더 전체의 메타데이터를 조회하고 다운로드가 필요한 161개 파일을 요청했다. 파일 삭제나 초기화는 하지 않았다.
   - CSV 다운로드를 하나씩 처리하는 기존 구조 자체는 이번 변경에서 수정하지 않았다. 파일이 다시 오프로드되면 지연이 재발할 수 있다.

## 검증

- 북마크 회귀 테스트: 수정 전 오류 259로 실패, 수정 후 성공. 손상 데이터 거부 테스트 포함.
- 전체 코어 테스트: 106개 통과.
- Mac 빌드 및 설치 앱 코드 서명 검증 성공.
- 실제 Mac 이벤트 191개, 미전송 0개. 공유 폴더와 이벤트 ID 집합 일치 확인.
- 191개 변경 파일 모두 iCloud 업로드 완료 속성 확인(대기 0, 상태 미확인 0).
- 사용자가 iPhone 잠금을 해제하고 앱을 연 뒤 저장소를 다시 복사하여 확인: iPhone 191개, Mac 191개, 양쪽 미전송 0개.
- 양쪽 이벤트 ID뿐 아니라 모든 이벤트의 JSON 내용도 일치한다. Mac에서 보낸 54개와 iPhone에서 보낸 17개가 양쪽에 반영됐다.

## 표시상 주의점

현재 상태 문구는 폴더의 모든 과거 기기 수신 확인을 검사한다. 사용하지 않는 이전 기기의 수신 기록이 남아 있으면 현재 두 기기가 일치해도 `상대 기기 확인 대기`가 표시될 수 있다. 이전 기기 기록은 삭제하지 않았다.
