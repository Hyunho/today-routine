# iCloud Drive 수동 전송 확인

- 설정 → 자동 동기화 → 지금 동기화에서 다운로드 요청, 기존 데이터 병합·폴더 저장, 업로드 요청 및 상태 확인 순서로 처리한다.
- 직접 업로드는 최신 OS에서 지원 표시가 있는 현재 기기의 불변 변경 JSON에 한정한다. 로컬 파일 무결성을 검사하고, 편집 가능한 CSV·다른 기기 파일에는 적용하지 않는다. 파일 동기화를 일시 중지하지 않는다.
- 지원 표시가 없으면 시스템 자동 업로드를 유지하고 그 사실을 표시한다. 파일 업로드 확인과 다른 기기 적용 확인을 구분한다. 상태를 확인할 수 없는 파일은 완료로 계산하지 않는다.
- 실제 Mac 폴더 `/Users/hyunho/Documents/TodayRoutine`은 iCloud 파일로 확인되었지만 직접 제어 지원 값은 없었다. 최신 파일 다운로드 요청은 수락됐으며 확인 시 로컬 파일은 최신 상태였다.
- 전체 코어 테스트 97개 통과. Mac 서명 빌드와 iPhone Release 서명 빌드 성공(1.0, 빌드 19).
- 현재 폴더에서는 직접 업로드 API 실행을 검증할 수 없다. 지원되는 제공자에서 별도 실기기 검증이 필요하다. 다른 기기까지 즉시 전달됨을 보장하지 않는다.
