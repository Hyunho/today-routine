# Apple 미리 알림 연동 구현 계획

사용자가 승인한 목록 선택·원본 직접 편집·완료 반영·오늘 마감 표시를 구현한다. 기존 일감은 유지하고 EventKit 항목은 별도 출처로 보여 준다. 직접 구현하며 기존 작업을 보존한다.

- [x] 독립적인 EventKit 접근 계층과 관찰 가능한 연결 모델을 추가한다. 권한 요청은 연결 버튼에서만 수행하고 선택한 목록 ID만 기기에 저장한다.
- [x] 날짜 변환, 권한 취소, 선택 목록 필터, 저장 실패, 오래된 조회 결과 무시를 단위 테스트한다. 외부 수정 충돌은 저장 전 비교 로직을 검토하고 실기기 검증 항목으로 남긴다.
- [x] 일감 탭에 목록 연결과 원본 추가·수정·완료 버튼을 넣는다. 쓰기 금지 목록은 조회만 허용한다. 저장 실패 시 편집 내용을 보존한다.
- [x] 오늘 탭에 선택한 날짜가 마감인 원본 항목을 표시하고 합계에 포함한다. 앱 활성화와 EventKit 변경 알림에 새로 조회한다.
- [x] iOS 17/macOS 14 권한 설명·맥 sandbox entitlement를 설정하고 프로젝트를 재생성한다.
- [x] 단위 테스트, 아이폰·맥 빌드와 시뮬레이터 UI 검증을 수행한다. 실제 iCloud 계정 간 동기화 여부는 별도 실기기 확인 항목으로 기록한다.

복사본과 동기화 ID를 기존 SwiftData/파일 동기화에 넣지 않는다. 편집은 제목·메모·마감일만 변경하고 반복·알림·우선순위 등 다른 원본 속성은 보존한다. 기존 날짜가 시간대를 가지면 앱의 한국 시간 기준으로 표시하고, 날짜를 변경하지 않았을 때 원본 DateComponents를 보존한다. 연결 해제는 선택만 지우며 미리 알림을 삭제하지 않는다.
