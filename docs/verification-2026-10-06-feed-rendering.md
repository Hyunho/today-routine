# 피드 본문 렌더링 검증

버전 1.0 (빌드 3). RSS/Atom 파서가 일반 텍스트 미리보기와 원문/형식을 함께 저장한다. 기존 JSON에는 선택 필드만 추가하여 읽음·저장 상태와 호환된다. 기존 본문은 새로고침으로 원문 서식을 복구한다.

- 전체 단위 테스트 86개 통과. Markdown 제목/강조/링크/목록/인용/코드/표, RSS 원문, Atom XHTML 구조, 안전한 링크와 문서 정책, 기존 JSON 호환성, 병합 후 상태와 원문 보존을 포함한다.
- 피드 UI 테스트 5개 중 목록·구독·위치/오류 격리 3개는 최초 실행에서 통과. 본문 2개는 최초 로드 URL 처리 수정 후 재실행하여 통과했다. WebKit의 loadHTMLString 첫 탐색은 about:blank 대신 baseURL을 사용할 수 있어 최초 로컬 문서 요청을 허용하도록 수정했다.
- 큰 글자·다크 모드에서 제목/강조/목록/인용/코드 스타일과 본문 마지막 문단까지 스크롤을 검증했다. HTML 표 표시와 본문 스크립트 실행 차단을 확인했다.
- 원격 이미지/동영상/스타일/스크립트는 자동 로드하지 않는다. 본문 링크는 http(s)만 외부 브라우저로 연다.
- 스크린샷: `docs/screenshots/feed-markdown.png` (테스트 데이터).
- 최종 본문 UI 결과: `/private/tmp/today-layout-build/Logs/Test/Test-TodayRoutine-2026.10.06_09-00-26-+0900.xcresult`.

맥은 빌드로 검증했고 실제 계정 피드의 모든 HTML/CSS 조합을 확인한 것은 아니다. 더 이상 서버 피드에 없는 과거 글의 제거된 HTML 서식은 복원할 수 없다.
